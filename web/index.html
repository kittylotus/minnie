Embeddings
  1. Enter your embedding provider’s /v1 URL and API key.
  2. Load the embedding models and choose a model that supports embeddings.
  3. Save embedding provider, then Ping embedding provider to check the connection.
  4. Select Build semantic index below. Keep Minnie running until the build finishes; an interrupted build can resume.

Minnie builds the database index automatically. Use the same embedding provider and model for indexing and searching. The answer model is configured separately.

The semantic index embeds the corpus with branch context. Building it sends dialogue to this provider and may incur usage charges. Interrupted builds resume from saved batches.
